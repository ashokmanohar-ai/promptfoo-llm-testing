## Reference Implementation

The open-source [Promptfoo LLM Testing and AI Red Teaming](https://github.com/ashokmanohar-ai/promptfoo-llm-testing) repository demonstrates prompt regression testing, deterministic and model-graded assertions, JSON Schema validation, RAG response testing, Azure model comparison, permanent security regressions, generated red-team probes and GitHub Actions quality gates.

Related publications extend these ideas into [LLM evaluation](https://github.com/ashokmanohar-ai/llm-quality-evaluation-harness/blob/main/WHITEPAPER.md), [LLM-as-a-Judge governance](https://github.com/ashokmanohar-ai/llm-quality-evaluation-harness/blob/main/publications/LLM_AS_A_JUDGE_FOR_QUALITY_ENGINEERING.md), and [Continuous AI Quality Engineering](https://github.com/ashokmanohar-ai/continuous-quality-engineering/blob/main/WHITEPAPER.md).
